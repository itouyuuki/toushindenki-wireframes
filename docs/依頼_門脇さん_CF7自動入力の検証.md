# 検証依頼：Contact Form 7 で製品の型番・品名をフォームに自動入力できるか

## 1. 何をしたいか

製品ページの「この商品を問い合わせる」ボタンを押すと、**型番と品名が入った状態で製品問い合わせフォームが開く**ようにしたい。
これが Contact Form 7（以下 CF7）で実現できるかを確かめてほしいです。

```
製品ページ
  └ 「この商品を問い合わせる」ボタン
       ↓  /contact-product/?your-model=TSD-POC2234AF&your-product=（品名）
製品問い合わせフォーム
  型番：TSD-POC2234AF        ← 最初から入っている
  品名：電動バリフォーカル…  ← 最初から入っている
```

**背景**：先方（真田様）によると、型番の書かれていない問い合わせが日常的に来ていて困っている。
8/5 の打合せで要望をもらい、10/08 の社内会議で門脇さんに検証をお願いすることになりました。

**大事な前提**：検証が終わるまで、先方には「できます」と言いません。結果は先方への回答の根拠になります。

---

## 2. やり方の第一候補：CF7 標準の `default:get`

CF7 には、**URL のパラメータをフォームの初期値にする機能が標準で付いています。**
フォームタグに `default:get` を付けると、同じ名前の GET パラメータの値が入ります。

```
[text* your-model default:get]
[text* your-product default:get]
```

→ `?your-model=TSD-POC2234AF` で開くと、型番欄に `TSD-POC2234AF` が入る（はず）。

**これで足りれば独自のプログラムは書かなくて済みます。** まずこれを試してください。
足りない場合だけ、3-⑤ のサーバー側の処理に進みます。

※ JavaScript で後から値を入れる方法は使いません（8/17 の会議で不可と判断済み）。

## 3. 確かめてほしいこと

時間は**項目ごとの上限**です。**超えそうになったら、途中でもその時点で伊藤に報告してください。**
（技術顧問の藤本先生からの指示です。調べ始めると時間がいくらでもかかるので、区切って進めます）

| # | 確かめること | 上限 | 合格の目安 |
|---|---|---|---|
| ① | 検証用 WordPress に CF7 を入れ、テスト用の製品問い合わせフォームを作る | 1時間 | フォームが表示されて送信できる |
| ② | `default:get` で**型番と品名の両方**が入るか | 1時間 | URL で開くと両方の欄に値が入っている |
| ③ | **日本語の品名**が文字化けしないか（下の「テスト用の値」を使う） | 30分 | 長い日本語の品名がそのまま入る。記号（`/` `・` `（）`）も崩れない |
| ④ | パラメータがないとき・空のとき | 30分 | エラーにならず、空欄で開く（一般の問い合わせとしても使える） |

**①〜④で計3時間、⑤⑥は必要なときだけ。**

## 4. やらなくていいこと

- 本番サーバー・先方のサーバーには触らない（検証はローカルだけ）
- 見た目・デザインは不要。項目が並んでいれば十分
- reCAPTCHA の設定は今回は対象外
- 製品ページ側のボタンを作り込む必要はない。URL を手で打って開ければ OK

---

## 5. 検証環境

- `C:\xampp\htdocs\wptest` を使うか、新しくローカルに WordPress を立ててください
- 使った **WordPress・CF7・PHP のバージョン**を控えておいてください（報告に書いてもらいます）
