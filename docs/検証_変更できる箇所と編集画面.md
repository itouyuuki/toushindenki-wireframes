# ワイヤーの「変更できます」箇所 — 先方が変更できるかの検証（2026-11-02）

ワイヤーで **「登録して変更できます」「自由に記入できます」** のラベルが付いた箇所を全ページから洗い出し、
先方が WordPress の管理画面から本当に変更できるかを、ローカルの wptest で実際に操作して確かめた。

- 環境：`C:\xampp\htdocs\wptest`（WordPress 7.1 日本語版）。検証用コードは
  `wp-content/mu-plugins/toushin-edit-areas-test.php`（追加欄・特徴タクソノミー・カテゴリーの追加欄の最小実装）
- 操作：テスト用管理者でログインし、ブラウザで入力 → 保存 → データベースに入ったことを確認
- **「標準」＝ WordPress にもともとある機能。「追加」＝テーマ側で数十行足す欄**（プラグインは使わない）

## 結論

**ラベルどおり、全13か所とも先方が管理画面から変更できる形で作れる。**
持たせ方が設計資料に無かった2か所（トップ⑥カタログ・会社案内④社長挨拶）も、11/02 に方針を決めた（下記）。

## 設計が抜けていた2か所 → 2026-11-02 に伊藤さんが案どおり決定

### 1. トップ⑥ カタログ：どの資料をトップに出すか ✅ 決定

資料（取扱説明書など）はすべて「資料」カテゴリーの投稿として登録する設計だが、
その中から「総合カタログ」1件をトップに出す決め方が決まっていなかった。

**決定：資料の種類（「資料」の子カテゴリー）に「カタログ」を足し、その最新1件をトップに出す。**
先方は新しいカタログを「カタログ」で登録するだけで、トップが切り替わる（TOPICS の新製品タグと同じ考え方）。

- 資料の種類は 10/08 資料の4つ（取扱説明書／仕様書／図面／アップデートバージョン）＋**カタログ**の5つになる
- ⚠ **ダウンロードページの絞り込みは8/5決定の4種類のまま**にする。カタログを絞り込みに出すかは実装時に除外できる
  （ダウンロードページにカタログを並べるかは先方に聞いていない）
- 表紙画像＝その資料の投稿のアイキャッチ、ボタン＝「資料ファイル」欄（表示のたびに添付IDから URL を作る）
- 先方が触る画面：**投稿 › 新規追加**（カテゴリー「資料 › カタログ」）

### 2. 会社案内④ 社長挨拶：本文の枠がもう埋まっている ✅ 決定

WordPress の本文は1ページ1か所で、会社案内の本文は⑤会社概要・⑥沿革で使う（論点10）。
社長挨拶（見出し・本文・署名・写真）を入れる場所が別に要った。

**決定：固定ページ「社長挨拶」を別に作り、その本文とアイキャッチ（代表者の写真）を会社案内ページに差し込む。**
先方は **固定ページ › 「社長挨拶」を編集** で書き換える。標準機能だけで済み、追加の欄は要らない。

- ページ内リンク③の「社長挨拶」は会社案内ページ内のこの部分に飛ぶので、見た目は今のワイヤーのまま
- 「社長挨拶」ページ単体の URL もできてしまう → 実装時に単体表示は会社案内へ転送するか、検索エンジンに出さない設定にする
- 写真は「あってもなくても」（ワイヤーの注記）なので、アイキャッチが空なら本文だけ全幅で出す
